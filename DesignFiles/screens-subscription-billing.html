Next.js Routes
app/(dashboard)/settings/billing/page.tsx — Main billing dashboard (Server Component + Client islands).
app/(dashboard)/settings/billing/payment-methods/page.tsx — Payment methods management sub-route.
Both require authentication — redirect to /login if no session.
NestJS Endpoints
GET /api/billing/summary — Current plan, billing cycle, next payment date, usage stats.
GET /api/billing/payment-methods — Returns Stripe PaymentMethods attached to customer.
POST /api/billing/payment-methods — Attach new PaymentMethod (Stripe token from frontend).
DELETE /api/billing/payment-methods/:id — Detach a payment method.
PUT /api/billing/payment-methods/:id/default — Set as default payment method.
GET /api/billing/invoices — Paginated invoice history from Stripe (query: ?page=1&limit=5).
GET /api/billing/invoices/:id/pdf — Redirect to Stripe-hosted invoice PDF.
POST /api/billing/change-plan — Body: { targetPlan: "enterprise", billingCycle: "yearly" } → Creates Stripe subscription update with proration.
POST /api/billing/cancel — Schedule cancellation at end of billing period (cancel_at_period_end: true).
Stripe Integration Details
Frontend: @stripe/stripe-js + @stripe/react-stripe-js — CardElement for PCI-compliant card collection.
Backend: stripe SDK — Customer, Subscription, PaymentMethod, Invoice APIs.
Webhooks: POST /api/webhooks/stripe — handles invoice.paid, invoice.payment_failed, customer.subscription.updated, customer.subscription.deleted.
Proration: Stripe's proration_behavior: 'create_prorations' on subscription update.
Card form uses Stripe Elements — raw card data never reaches CoLearner servers.
State Management
Zustand store: useBillingStore — { plan, billingCycle, paymentMethods, invoices, usage }.
@tanstack/react-query for server state: useBillingSummary(), useInvoices(page), usePaymentMethods().
Optimistic update on plan change: show new plan immediately, revert on webhook failure.
Toast via react-hot-toast or custom toast component — auto-dismiss 5s.
