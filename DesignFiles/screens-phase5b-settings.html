Privacy
CoLearner is built with privacy-first principles
No raw content stored. CoLearner never stores original URLs, transcripts, or video IDs. Only SHA256 hashes and extracted concepts are kept in the database.
Local-first processing. All AI inference runs on your machine via Ollama. No data leaves your device during extraction or judging.
Data deletion. You can export and delete all your data at any time. Deletion is permanent and irreversible.

NestJS Endpoints
GET /api/settings — Returns all user settings as a flat object.
PUT /api/settings — Partial update, accepts any subset of settings keys.
POST /api/user/export/json — Generates full data export (extractions + recall_attempts + settings).
POST /api/user/export/csv — Generates CSV of recall_attempts only.
DELETE /api/user/account — Requires confirmation token, permanently deletes all data.
POST /api/auth/connect/google / POST /api/auth/connect/apple — OAuth link flows.
Privacy Architecture
Privacy rules enforced at DB layer: video_id_hash = SHA256(video_id), raw URLs never stored.
Local-first: Ollama inference on device. Pro tier (future) will use hosted API with opt-in consent.
Export uses streaming JSON for large datasets: @nestjs/common StreamableFile.
