NestJS Endpoints
GET /api/user/profile — Returns name, email, skill, joined date, active_state, avatar.
GET /api/user/stats — Total recalls, pass rate, streak, best streak.
GET /api/ring/progress — All 3 sources with progress counts and unlock criteria.
GET /api/user/achievements — All badges with earned/locked status + dates.
GET /api/recall/sessions?page=1&limit=10 — Paginated session history.
GET /api/mastery/concepts — All concepts with strength (Strong/Fair/Weak), EF, last review date.
PUT /api/user/profile — Update name, skill, avatar (multipart/form-data for file upload).
Concept Strength Classification
Strong: EF ≥ 2.5 AND last 3 recalls all passed.
Fair: EF ≥ 1.8 OR mixed pass/fail in last 3.
Weak: EF < 1.8 OR last recall was a fail.
These thresholds are configurable via GET /api/settings/thresholds.
