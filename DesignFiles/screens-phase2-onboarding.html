React Components
<SignUpPage /> → uses <AuthLayout /> wrapper, <SocialAuthButtons />, <FormField /> with real-time validation via react-hook-form + zod schema. Password strength calculated client-side using zxcvbn library. The green validation checks animate in with framer-motion AnimatePresence.
NestJS Endpoints
POST /auth/register — Validates email uniqueness, hashes password with bcrypt, creates user record, returns JWT + refresh token pair. Google OAuth: GET /auth/google → GET /auth/google/callback via Passport strategy. Apple: POST /auth/apple. All tokens are httpOnly cookies + CSRF protection.
