Next.js: app/(auth)/signup/page.tsx
Client component ('use client') using <AuthLayout> split wrapper. Form via react-hook-form + zod schema. Real-time field validation on blur. Password strength via zxcvbn. Social auth buttons redirect to NestJS OAuth endpoints /api/auth/google and /api/auth/apple. SVG icons from lucide-react. The Apple icon uses the official Apple SVG path. Auth state managed via next-auth or custom JWT provider in app/providers.tsx.
NestJS: src/auth/auth.controller.ts
POST /api/auth/register — body: { name, email, password }. Validates unique email, hashes via bcrypt (12 rounds), creates user, returns { accessToken, refreshToken }. Google: GET /api/auth/google via Passport GoogleStrategy. Apple: POST /api/auth/apple via passport-apple.

NestJS: POST /api/auth/login
Returns { accessToken (15min), refreshToken (7d) }. Rate limited: 5 attempts / 15min per IP via @nestjs/throttler. After 5 failures → 30-min lockout + email alert. POST /api/auth/forgot-password sends magic link (1hr TTL). POST /api/auth/refresh rotates refresh token.

Full User Flow
app/(auth)/signup → app/(onboarding)/profile (Step 1) → app/(onboarding)/goal (Step 2) → app/(onboarding)/skills (Step 3) → app/(onboarding)/welcome → app/(dashboard). All steps skippable except signup. Skip sets defaults: goal = "Build Knowledge", time = "15 min", skills = empty (show all). Total: ~2 min. Next.js middleware (middleware.ts) checks onboarding_completed flag via JWT — incomplete onboarding redirects back. Route groups (auth), (onboarding), (dashboard) each have their own layout.tsx.
Responsive Behavior
Auth split-screen: on screens < 1024px, the brand panel hides and form goes full-width with a minimal logo header. Onboarding wizard: stays centered, max-width 620–720px. Skill grid: 4 cols → 3 cols → 2 cols. Goal cards: 4 cols → 2 cols. All animations respect prefers-reduced-motion. Styles: Tailwind CSS + CSS modules in app/(auth)/auth.module.css. Shared components in components/ui/ (Button, Input, Card, etc.).
