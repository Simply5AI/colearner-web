Next.js Architecture: app/(dashboard)/layout.tsx
app/(dashboard)/layout.tsx renders <AppShell> with <Sidebar> + {children}. Dashboard route: app/(dashboard)/page.tsx is a Server Component that fetches initial data via fetch() to NestJS, then passes to client sub-components: <GreetingBanner>, <StatsRow>, <NotificationAlert>, <SourceProgressCard>, <RecallQueue>, <QuickCapture>, <StreakTracker>. Interactive components are 'use client'. Server state via @tanstack/react-query hydrated from RSC, UI state via zustand. Sidebar is a shared component in components/layout/Sidebar.tsx.
NestJS API: src/dashboard/dashboard.controller.ts
GET /api/dashboard/stats → { totalRecalls, passRate, activeConcepts, streak }. GET /api/recall/queue → due + failed items (merges SM-2 due + failed subquery from recall_attempts). GET /api/user/activity → recent activity feed (paginated). GET /api/source/progress → current source, milestones, available states. All protected by @UseGuards(JwtAuthGuard). Next.js fetches these in Server Components with cookies() forwarded for auth. Client components use @tanstack/react-query for polling/refetch.

Next.js: app/(dashboard)/capture/page.tsx
Client component ('use client') with URL input form. On submit, calls NestJS POST /api/capture/extract with { url: string }. Subscribes to progress via SSE endpoint GET /api/capture/stream/:extractionId using EventSource. Concept cards render progressively as chunks complete. NestJS side: CaptureController fetches transcript via youtube-transcript, chunks to 4000 chars / 300 overlap, runs Pass 1 (llama3.2:3b) per chunk, then Pass 2 (gemma2:9b) for question gen. Stores in extractions table with SHA256 hash of video_id — never raw URL (privacy rule). Uses @nestjs/event-emitter for real-time progress.

NestJS: src/mastery/mastery.controller.ts
GET /api/mastery/stats?range=30d → aggregate stats. GET /api/mastery/daily?range=30d → daily pass rate array for chart. GET /api/mastery/by-type → breakdown by Open/MCQ/Cloze. GET /api/mastery/concepts?page=1&sort=ef → paginated ledger with SM-2 fields. GET /api/mastery/export → CSV download via StreamableFile. All data sourced from recall_attempts table. Uses @nestjs/swagger for API docs.
Next.js: app/(dashboard)/mastery/page.tsx
Server Component fetches initial stats and passes to client chart components. Uses recharts ('use client') for the bar chart and SM-2 distribution. <ConceptLedger> table built with @tanstack/react-table for sorting, filtering, pagination — client component with react-query for pagination. Status badges computed from EF and pass rate: Strong (EF ≥ 2.5 + ≥80%), Fair (EF ≥ 2.0 + ≥60%), Weak (below). Date range picker updates all queries via react-query invalidation. CSV export triggers direct download from NestJS endpoint.
