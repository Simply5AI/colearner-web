Nudge Architecture (from Context Anchor)
3 nudge types defined in CL-021:
interval: Fires at user-configured interval (30m/1h/2h/4h/daily) after new captures.
sm2_due: Fires when daemon detects sm2_due_date <= today items exist.
contextual: Phase 2 stretch goal — detect concept overlap between new capture and existing recall_attempts.
Quiet hours: session state keys already scaffolded as nudge_quiet_start / nudge_quiet_end.
Delivery: plyer or playsound + platform-native (notify-send / osascript / Windows toast).
Web app: use Web Push API + service worker for browser notifications.
